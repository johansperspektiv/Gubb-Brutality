🚨 AKUT OMHÄNDERTAGANDE
SKOTTSKADA / VÅDASKOTT

L – LIVSFARLIGT LÄGE

Kontrollera → Åtgärda

  • Är platsen säker?
  • Eldupphör! Säkerställ vapnen.
  • Flytta till skydd från yttre fara om möjligt.
  • Larma 112.

C – LIVSHOTANDE BLÖDNING

Kontrollera → Åtgärda

  • Kraftig blödning?
  • Tourniquet / avsnörande förband
  • Sårpackning
  • Håll tryck!

A – AIRWAYS / LUFTVÄG

Kontrollera → Åtgärda

  • Fri luftväg?
  • Kan personen svara på tilltal?
  • Rensa mun vid behov.
  • Haklyft / käklyft.
  • Sänkt medvetande → stabilt sidoläge om andningen är normal.

B – BREATHING / ANDNING

Kontrollera → Åtgärda

  • Kan personen räkna till 10?
  • Nej → kontrollera bröstkorgen.
  • Andas båda sidor av bröstkorgen liksidigt?
  • Skottskada på bröstkorg → täck med lufttätt förband.
  • Försämring → 112 / följ instruktioner.

C – CIRCULATION / CIRKULATION

Kontrollera → Åtgärda

  • Handledspuls?
  • Nej → kontrollera igen.
  • Är blödningen stoppad?
  • Leta efter inre blödning: bröstkorg, buk, bäcken, ben.
  • Blödning kvar → nytt avsnörande förband / sårpackning / tryckförband.

D – DISABILITY / MEDVETANDE

Kontrollera enligt AVPU

  • A – Alert: Vaken
  • V – Voice: Reagerar på tilltal
  • P – Pain: Reagerar på smärta
  • U – Unresponsive: Reagerar inte

E – EXPOSURE / HELA PERSONEN

Kontrollera → Åtgärda

  • Leta efter ytterligare synliga skador.
  • Kontrollera fram- och baksida.
  • Förhindra avkylning.
  • Ge första förband.
  • MIST till ambulans.
  • Patron ur – avlägsna ammunition om det kan göras säkert.
  • Förbered för avtransport.

🔴 MIST – RAPPORTERA TILL 112/AMBULANS

  • M – Mechanism: Vad har hänt?
  • I – Injuries: Vilka skador?
  • S – Signs: Medvetande, andning, blödning.
  • T – Treatment: Vad har du gjort?

KOM IHÅG

L → C → A → B → C → D → E
Stoppa det som dödar först.
